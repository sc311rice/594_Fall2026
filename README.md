# IEEE Midterm Report

This folder is self-contained and can be uploaded to a GitHub repository as-is.

## Build

Run `./build.ps1` in PowerShell. The included script uses `tectonic.exe` from this folder when present, or a system-installed Tectonic executable. On Overleaf, upload the folder contents and compile `main.tex` with pdfLaTeX.

## Submission checklist

- Submit `main.pdf` to Canvas.
- Upload this entire folder to the project GitHub repository, including `main.pdf`.
- The paper is designed to compile to exactly three pages in IEEE conference format and contains three numbered figures.
